# C/C++ Programming – Week 10 Quiz

## Question 1
What is the main difference between a character and a string in C?

A) A character uses 2 bytes, and a string uses 1 byte.
B) A character represents one symbol, while a string is a sequence of characters.
C) A character and a string are the same.
D) A string can contain only numbers.

Answer: B

## Question 2
What is the purpose of the null character (\0) in a string?

A) To start a string.
B) To store a number.
C) To indicate the end of a string.
D) To delete a character.

Answer: C

## Question 3
Which function is used to calculate the length of a string in C?

A) strcpy()
B) strlen()
C) strcmp()
D) strcat()

Answer: B

## Question 4
What is the main purpose of a structure (struct) in C?

A) To store only integer values.
B) To create loops.
C) To combine variables of different data types into one group.
D) To compare strings.

Answer: C

## Question 5
What is the main feature of a union in C?

A) Each member has a separate memory location.
B) All members share the same memory location.
C) It can store only characters.
D) It cannot contain different data types.

Answer: B
